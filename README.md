# เหมียววิ่งป่า

เกมแพลตฟอร์มเดินด้านข้าง 2D ธีมป่า ตัวเอกเป็นแมวส้มวิ่งสองเท้า — 3 ด่าน (ชายป่า · ป่าลึก · ป่ายามค่ำ) สร้างด้วย Phaser 4 + Vite
เป็นเว็บไฟล์ล้วน โฮสต์แบบ Static ได้ ไม่ต้องมีเซิร์ฟเวอร์ฝั่งหลังบ้าน

## วิธีเล่น

| ทำอะไร | คีย์บอร์ด | มือถือ |
|---|---|---|
| เดินซ้าย/ขวา | ← → หรือ A D | ปุ่ม ◀ ▶ มุมซ้ายล่าง |
| กระโดด (กดค้าง = สูงขึ้น) | Space / ↑ / W | ปุ่ม ▲ มุมขวาล่าง |
| ปิด/เปิดเสียง | M | แตะ "เสียง: เปิด" มุมซ้ายบน |
| เล่นต่อหลังชนะ | Enter | แตะปุ่ม |

มือถือแนวตั้ง: เกมหยุดและขึ้นปุ่ม "พลิกเป็นแนวนอน" (ขอเต็มจอ + ล็อกแนวจอ — ใช้ได้บน Android Chrome/Edge/Firefox; iPhone/iPad เบราว์เซอร์ไม่อนุญาต ต้องหมุนเครื่องเอง) พอเป็นแนวนอนแล้วเกมเล่นต่อเอง

เก็บเหรียญอุ้งเท้า เหยียบหัวด้วงเพื่อกำจัด หลบพุ่มหนามและลำธาร ถึงบ้านต้นไม้เพื่อจบด่าน · แตะตอไม้ป้ายอุ้งเท้า (Checkpoint) เพื่อบันทึกจุดเกิด

## พัฒนา

ต้องมี Node.js (ทดสอบกับ v24)

```bash
npm install
npm run dev        # เปิด http://localhost:5173 (ตอนพัฒนามีแผงปรับค่าสดมุมขวาบน)
```

ตอน `npm run dev` เท่านั้น:
- `?level=2` ท้าย URL เริ่มที่ด่านนั้นตรง ๆ · `?touch` แสดงปุ่มสัมผัสบนคอม
- คอนโซลเบราว์เซอร์ (F12): `await __reach(0)` ตรวจว่าด่านเล่นถึงบ้านต้นไม้ได้ (0 = ด่าน 1)

รายละเอียดโครงสร้าง ค่าปรับแต่ง การสร้างภาพ/เสียง/แผนที่: ดู [GAME_PROJECT.md](GAME_PROJECT.md) · แผนการสร้าง: [PLAN.md](PLAN.md)

## ปล่อยให้คนเล่น (Static Hosting)

```bash
npm run release    # build + เก็บเป็นรุ่นที่ย้อนกลับได้ที่ releases/v<เวอร์ชัน>/
```

1. นำโฟลเดอร์ `releases/v1.0.1/` (รุ่นล่าสุด ดู `releases/LATEST.txt`) ทั้งโฟลเดอร์ไปวางบนโฮสต์แบบ Static อะไรก็ได้ (GitHub Pages, Netlify, Cloudflare Pages, nginx, Apache/XAMPP ฯลฯ) จะวางที่ราก หรือโฟลเดอร์ย่อยก็ได้ (ใช้ path แบบสัมพัทธ์)
2. **ต้องเปิดผ่านเซิร์ฟเวอร์** (http://…) ห้ามดับเบิลคลิก `index.html` เปิดตรง ๆ (file://) เพราะเบราว์เซอร์ไม่ยอมโหลดโมดูล JavaScript
3. ไม่ต้องตั้งค่า MIME พิเศษ (ไฟล์แผนที่ `.tmj` เป็นนามสกุลไม่รู้จักก็ใช้ได้)
4. ขนาดรวม ≈ 3.7 MB (เพลงพื้นหลัง .wav ≈ 1.7 MB ใหญ่สุด)

**ย้อนกลับเมื่ออัปเดตแล้วพัง:** นำโฟลเดอร์รุ่นเก่า (เช่น `releases/v1.0.0/` ก่อนเพิ่มปุ่มพลิกจอ) กลับไปโฮสต์แทนรุ่นปัจจุบัน · รุ่นใหม่ต้องเพิ่มเลข `version` ใน `package.json` ก่อนรัน `npm run release` (สคริปต์ไม่เขียนทับรุ่นเก่า) · `releases/LATEST.txt` บอกรุ่นล่าสุด

> ถ้าใช้ git: โฟลเดอร์นี้ยังไม่ได้เป็น git repo (`git init` ได้เมื่อต้องการ) — `node_modules/` และ `dist/` ถูกตั้งให้ไม่ติดตามไว้แล้ว

## ภาพและเสียง

ภาพทั้งหมดและเสียงส่วนใหญ่สังเคราะห์ด้วยสคริปต์ใน `tools/` (ไม่ได้ใช้ PixelLab/ElevenLabs) — เปลี่ยนเป็นไฟล์จริงได้โดยวางทับชื่อและขนาดเฟรมเดิม ดู GAME_PROJECT.md หัวข้อ "ข้อกำหนดภาพ" และ "เสียงและหน้าจอ"
